# پنل مدیریت محتوا

پنل در مسیر `/admin/` است و در منو، فوتر و دکمه‌های سایت نمایش داده نمی‌شود. صفحهٔ ورود قابل مشاهده است، اما دریافت محتوا و انتشار فقط با نشست معتبر سرور انجام می‌شود. مسیر پنل نیز از ایندکس موتورهای جست‌وجو خارج شده است.

## امکانات

- ویرایش مشخصات، راه‌های ارتباطی، متن همهٔ صفحه‌ها و لینک‌ها
- افزودن، حذف و مرتب‌سازی نمونه‌کار، خدمت، دوره، تعرفه، سؤال و نظر واقعی
- کتابخانهٔ تصویر با تبدیل محلی JPG/PNG/WebP به WebP بهینه
- پشتیبان و بازیابی JSON برای متن‌ها و تنظیمات
- ثبت اتمیک تغییرات در شاخهٔ `main` گیتهاب و نمایش وضعیت انتشار Pages
- تشخیص تعارض و جلوگیری از بازنویسی تغییرات هم‌زمان

## امنیت و استقرار

Worker در `cms/wrangler.jsonc` تعریف شده و نشست‌ها و محدودیت تلاش ورود در Durable Object مبتنی بر SQLite نگهداری می‌شوند. رمز مستقیم ذخیره نمی‌شود؛ فقط salt و خروجی PBKDF2-SHA256 در Secrets کلادفلر ثبت می‌شوند. توکن گیتهاب باید فقط به مخزن همین سایت محدود باشد و مجوزهای `Contents: Read and write` و `Actions: Read` داشته باشد.

Secrets لازم:

```text
ADMIN_USERNAME
ADMIN_PASSWORD_SALT
ADMIN_PASSWORD_HASH
GITHUB_TOKEN
```

بعد از انتشار Worker، مقدار `apiBase` در `public/admin-config.json` باید نشانی HTTPS همان Worker باشد. `ALLOWED_ORIGINS` نیز باید دقیقاً مبدأ سایت باشد؛ localhost را به تنظیمات Production اضافه نکنید.

## روش استفاده

۱. آدرس مستقیم `/admin/` را باز کنید و وارد شوید.

۲. بخش موردنظر را ویرایش کنید. شناسهٔ اثر و مسیر خدمت باید لاتین و یکتا باشند و دستهٔ اثر باید در فهرست دسته‌های گالری وجود داشته باشد.

۳. برای افزودن تصویر، فایل JPG، PNG یا WebP تا ۱۵ مگابایت را انتخاب کنید. مرورگر آن را به WebP با حداکثر ضلع ۲۴۰۰ پیکسل و حداکثر حجم دو مگابایت تبدیل می‌کند. در هر انتشار حداکثر سه تصویر جدید مجاز است. سپس تصویر را در فیلد محتوای مربوط انتخاب کنید.

۴. «بررسی و انتشار» را بزنید. تا قبل از تأیید نهایی، تغییرات فقط در حافظهٔ صفحه هستند. فایل پشتیبان JSON شامل متن و تنظیمات است، اما باینری تصاویر هنوز منتشرنشده را شامل نمی‌شود.

۵. ثبت در گیتهاب آغاز فرایند انتشار است. دکمهٔ «بررسی وضعیت انتشار» موفقیت GitHub Actions و نمایش نسخهٔ عمومی را مشخص می‌کند.

تصویرِ در حال استفاده قابل حذف نیست. ابتدا محل استفاده را تغییر دهید. حذف رسانه از نسخهٔ فعلی، نسخه‌های قدیمی آن را از تاریخچهٔ گیت پاک نمی‌کند.

## بررسی توسعه‌دهنده

```sh
npm run typecheck
npm test
npm run build:pages
npm run cms:bundle
```

آزمون‌های CMS ورود، خروج، نشست منقضی، محدودیت تلاش ناموفق، CORS، اعتبارسنجی لینک و WebP، تعارض نسخه، commit بدون force و جلوگیری از حذف تصویر در حال استفاده را پوشش می‌دهند.
